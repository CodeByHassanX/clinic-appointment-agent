## 1. Project Overview
The Clinic Appointment Agent is an AI-powered appointment booking chatbot designed for clinics and healthcare service providers. It leverages natural language processing to identify patient intent, answer clinic-related FAQs using RAG, and automate appointment management.

## 2. Technical Stack
- **Frontend:** Next.js, React, Tailwind CSS
- **Backend:** Python, FastAPI
- **Database:** Supabase (PostgreSQL)
- **AI & Automation:** Flowise/Langflow (LLM routing), n8n (Webhooks & Workflows)
- **Integrations:** Google Calendar, Gmail (via n8n)

## 3. Key Features Delivered
1. **Intelligent Intent Detection:** Distinguishes between booking, cancelling, rescheduling, and general FAQs.
2. **Automated Slot Validation:** Validates doctor availability, working hours, and prevents double bookings in real-time.
3. **End-to-End Automation:** Seamlessly updates Supabase, creates/modifies Google Calendar events, and sends email confirmations.
4. **Professional UI:** A modern Next.js medical dashboard for patient interaction.
